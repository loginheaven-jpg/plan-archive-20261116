# 예봄일정 사용 안내

## 한눈에 확인하기

일반 교회 일정은 **로그인 없이 열람**한다. **입력·수정·취소 등 편집할 때만** 교적부의 기존 이메일/전화번호·비밀번호로 로그인한다. 이미 유효한 교적부 로그인이 있으면 다시 입력하지 않는다.

왼쪽 맨 위 ‘전체 선택’ 체크박스로 모두 켜거나 끈다. 아래에서 필요한 부서를 함께 고를 수 있다. 중간 체크 표시는 일부 부서만 선택한 상태다. ‘전교회 대상도 함께’를 켜면 선택한 주관부서 외에도 전체 성도가 참여하는 공개 범위 내 행사를 함께 볼 수 있다. 주관부서 ‘전교회’의 원본 예산 책임 조직은 당회이며, 실제 참여 대상과는 별개다.

연간은 열두 달의 행사 밀도를, 월간은 날짜별 약속을, 목록은 큰 글씨로 시간·장소를 읽는 데 적합하다. 휴대폰은 목록으로 시작한다. 큰 글씨 버튼은 목록 중심으로 확대한다. 오늘 버튼은 한국의 오늘이 속한 연월로 돌아간다.

연간에서 월 이름이나 카드의 빈 곳을 누르면 해당 월간으로 이동한다. 연간·월간 모두 날짜에 볼 수 있는 일정이 한 개면 바로 상세를, 여러 개면 그날 목록을 연다. 일정이 없는 날은 편집 권한이 있을 때만 그 날짜의 입력창이 열린다. 교회력 참고 표시는 실제 행사 수에 포함되지 않는다. 행사 제목을 직접 누르면 언제나 그 행사 상세를 연다.

## 등록과 변경

실제 교회 계정으로 로그인하고 부서 담당 권한을 받아야 입력할 수 있다. 일정 이름·날짜·주관부서를 적고 종일 또는 시간을 고른다. 여러 날 일정은 마지막 날짜를 지정한다. 자정을 넘으면 다음 날을 마지막 날짜로 지정한다. 참여 대상과 공개 범위를 따로 선택한다.

전체 공개 일정의 안내·장소는 공개 게시판과 구글 캘린더에도 표시된다. 개인정보와 준비 담당자 메모는 ‘담당자 내부 메모’에 적는다. 교인공개는 승인된 로그인 성도에게, 주관부서 담당자공개는 해당 조직 권한이 있는 사용자에게만 보인다. 내부 메모는 편집 가능한 담당자만 보는 것이 원칙이다.

입력자와 수립일은 수정하는 필드가 아니다. 서버가 현재 로그인 사용자의 이름과 최초 등록 시각으로 기록한다. 상세에서 최초 기록과 마지막 변경자·변경일을 확인한다. 변경 이력을 펼치면 날짜·시간·장소 같은 변경 전후를 읽을 수 있다. 최초 수립 기록은 수정 뒤에도 남고 아무것도 바꾸지 않은 저장은 변경일을 갱신하지 않는다.

반복 일정을 수정할 때는 ‘이번 회차’와 ‘반복 전체’를 구별한다. 한 회차의 시간·장소는 예외로 남고 다른 회차는 유지된다. 주관부서·참여 대상·공개 범위·반복 규칙 변경은 반복 전체에서 한다. 취소는 이유를 남기고 최근 변경에서 확인한다. 삭제는 휴지통에 보관하며 권한이 있는 담당자가 복구할 수 있다. 반복 전체의 삭제와 한 회차 취소는 서로 다르다.

저장 중에는 버튼이 잠기고 실패한 입력은 남는다. 다른 사람이 먼저 변경했다는 안내가 나오면 최신 상세를 확인한 뒤 변경을 다시 적용한다. 서버 응답이 불확실하면 같은 내용을 유지해 재시도하고 임의로 새로운 등록을 반복하지 않는다.

## 공유와 개인 캘린더

공유하기에서 공개 게시판 주소를 복사한다. 현재 선택한 부서·연월·보기 방식을 담지만 내부 일정은 공개하지 않는다. 공개 게시판에서도 부서와 보기 방식을 바꿀 수 있다. 이번 주 안내 복사는 공개 일정만 포함하며 생성시각을 함께 적는다. 화면 인쇄는 현재 월간·연간·목록을 인쇄한다.

운영 서비스가 공개된 후 PC Google Calendar의 ‘다른 캘린더 + → URL로 추가’에 ICS 구독 주소를 넣는다. 처음 추가는 PC에서 한다. 휴대폰에서는 같은 Google 계정의 이 캘린더를 표시한다. 삼성 캘린더도 연결된 Google 계정의 표시·동기화를 확인하되 기기와 앱 버전에 따른 차이를 확인한다.

구독은 읽기 전용이고 개인 일정은 이 서비스로 가져오지 않는다. 구글의 갱신 지연은 서비스가 정하지 못하므로 급한 변경은 예봄일정의 최근 변경에서 확인한다. ICS 파일 다운로드 후 가져오기는 한 번의 복사이며 자동 갱신 구독이 아니다. 개발 미리보기 주소 대신 확정된 운영 주소로 구독한다.

## 교회력과 장소

절기는 한국 개신교의 서방 그레고리력 기준 참고다. 부활주일·성령강림·대림절·성탄절 같은 표시는 실제 등록 행사나 휴무를 의미하지 않는다. 추수감사주일 등 교회별 관행은 관리자가 정하며 기본값을 교회의 확정 계획으로 오인하지 않는다.

관리자가 등록한 장소를 고르면 같은 장소의 겹치는 일정을 안내한다. 이름을 직접 입력한 장소는 정규화된 예약 공간이 아니므로 자동 충돌 안내가 제한된다. 경고는 참고이며 장소 예약 승인 시스템을 대신하지 않는다. 내부 행사의 이름·시간을 경고로 외부에 노출하지 않는다.

## 관리자가 처음 준비할 일

보호된 환경설정에서 운영 주소·최초 실제 관리자 사용자 ID를 연결하고 교적부의 공유 쿠키 도메인 .yebom.org를 확인한다. 별도 봉인키 복사는 필요하지 않다. 가상 계정으로 대신하지 않는다. 실제 관리자가 로그인한 후 `/settings`에서 교회력·장소와 실제 로그인한 사용자의 부서 권한을 지정한다. 예산 금액 연계 검색은 Phase 2에서 추가하며 이 서비스의 등록이 재정부 예산을 자동 변경하지 않는다.

## 연초에 한 해의 일정을 한꺼번에 입력하기

목록 화면 또는 왼쪽 메뉴에서 **연간계획 입력**을 연다. 조회에서 한 부서를 선택했다면 입력 부서가 전달된다. 여러 부서를 조회하던 경우에는 입력할 주관부서를 한 번 고른다. 조회 필터와 입력 부서는 다른 역할이며 담당 권한이 있는 부서만 등록할 수 있다.

연도를 고정하고 날짜와 일정 이름을 한 줄씩 이어서 쓴다. 월간 달력을 넘길 필요가 없다. 부서를 바꾸면 새 행의 기본 부서가 바뀌며 이미 쓴 행은 그대로다. 개별 행의 추가 설정에서 주관부서·시간·장소·참여 대상·공개 범위·반복·안내를 조정한다. 새 행의 기본값은 소속 부서 참여·로그인 없는 전체공개이며 등록 전 확인할 수 있다.

**초안 저장**은 내 로그인 사용자 소유의 작성 중 계획을 서버에 보관한다. 아직 확정되지 않은 날짜는 `날짜 미정` 또는 `7월 미정`으로 적어 둘 수 있다. 미정 행과 저장만 한 초안은 달력·공개 게시판·구글 구독에 나오지 않는다. 다시 열어 작성할 수 있으며 이동 전 미저장 경고와 저장 실패 안내를 확인한다.

**엑셀 붙여넣기**에서는 날짜·제목·장소 등 열을 맞춰 미리 본 뒤 행을 추가한다. 표의 수식을 실행하는 기능은 아니다. **지난해 계획 복사**에서는 내 권한으로 볼 수 있는 행사를 선택한다. 취소·삭제 및 이미 종료일 없이 계속되는 모임은 새해에 중복 등록하지 않도록 기본 복사 대상에서 제외한다. 복사 뒤에는 요일·교회력과 실제 날짜를 다시 확인한다. 윤년 2월 29일을 평년으로 옮겼을 때 임의로 다른 날짜로 바꾸지 않는다.

작성 후 **검토**에서 등록할 행과 건수·부서·공개 범위를 확인한다. 날짜 미정이나 잘못된 행은 보관만 하고 등록 대상에서 제외한다. 중복 의심·교회력·열람 가능한 전교회 행사·등록 장소의 겹침 안내는 참고이며 예약 승인이 아니다. 선택한 유효 행은 한 번에 등록되거나 모두 실패한다. 서버가 실제 입력자·수립일·변경 이력을 기록한다. 응답이 불확실하면 같은 초안과 행을 유지해 재시도한다. 이미 등록된 행은 초안에서 다시 등록하지 않고 원본 일정에서 수정한다.

## 정기모임의 기간과 종료일 없는 일정

날짜 표현 입력의 연도 없는 `10/10`은 선택한 계획 연도의 10월 10일이다. 일반 일정의 `7/20~7/22`는 여러 날 행사이고, 반복 표현의 범위는 첫 모임을 찾는 시작일과 마지막 회차의 시작일 기준이다.

- `1/10부터 3/31까지 매주 수요일 오후8시`: 해당 시작 범위부터 3월 31일 이내의 수요일 모임만 등록한다.
- `10/10부터 계속 수요일8시`: 10월 10일 이후 수요일에 종료일 없이 반복한다. ‘8시’만으로는 오전·오후를 알 수 없으므로 실제 시간 선택·확인 후 등록한다.
- `10/10부터 계속 수요일 오후8시`: 종료일 없이 매주 수요일 20:00 시작이다. 적용된 종료 시간도 확인한다.
- 매월 둘째 주일 등은 반복 설정의 **몇째 주의 특정 요일**을 사용한다. 시작일이 해당 요일이 아니면 그 이후 첫 해당 요일부터 발생한다.

단건 입력의 반복 설정에서도 **종료일 없이 계속 반복**을 선택할 수 있다. 종료일 있는 모임은 마지막 회차가 시작할 수 있는 날짜를 지정한다. 10월 10일이 수요일이 아니면 10월 10일에 가짜 첫 모임을 만들지 않는다. 달력과 구글 구독 모두 실제 첫 해당 요일부터 시작한다.

계속 반복은 한 시리즈와 회차 예외로 보관하며 무한 개의 일정을 미리 저장하지 않는다. 필요한 연도나 조회 기간의 모임만 표시한다. ‘이번 회차’ 수정·취소는 다른 회차에 영향을 주지 않고, 전체 중단은 반복 전체 취소 또는 반복 종료일 수정으로 처리한다. 계속 반복의 장소 검토는 명시된 유한 기간을 대상으로 하므로 먼 미래의 모든 충돌을 보장하는 것은 아니다.

## 입력 중 로그인 확인이 필요한 경우

로그인이 만료되거나 편집 권한이 바뀌어도 작성 중인 단건 입력을 자동으로 버리지 않는다. 입력창에서 내용을 보관한 채 숨기고 저장을 차단한다. **새 창에서 교적부 로그인**으로 기존 계정을 연결한 뒤 원래 입력창의 **로그인 상태 다시 확인**을 누르면 같은 계정의 현재 편집 권한을 확인해 이어 쓸 수 있다. 다른 계정에 기존 입력을 자동 이전하지 않는다. 인증 확인은 서버에서도 다시 수행하므로 예전 이름·권한으로 대신 저장되지 않는다.

승인 대기나 프로필 미완료 안내가 나오면 교적부에서 해당 절차를 완료한다. 비밀번호 재입력 반복으로 해결되는 문제와 구분한다. 이 안내가 있어도 일반 공개 일정 열람은 가능하다. 로그인 유지·현재 공유 쿠키가 유효하면 로그인 버튼에서 자격정보를 다시 입력하지 않고 연결한다.

## 자동 일정 편집 권한

교적부 수퍼어드민·어드민·목자·초원지기·담임목사 중 하나이거나 재정권한이 제직이면 전체 부서 일정 편집 권한을 자동으로 확인합니다. 두 조건을 동시에 갖출 필요는 없습니다. 중앙에서 승인·프로필·비밀번호 조건을 완료한 계정에 적용되며, 조건이 해제되면 다음 요청부터 자동 편집이 해제됩니다. 일정은 로그인 없이 열람할 수 있고, 자동 대상이 아닌 일반 성도는 별도 담당 부서 권한이 있어야 입력·수정할 수 있습니다.
