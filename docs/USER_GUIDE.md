# 예봄일정 사용 안내

## 한눈에 확인하기

왼쪽 맨 위 ‘전체 선택’ 체크박스로 모두 켜거나 끈다. 아래에서 필요한 부서를 함께 고를 수 있다. 중간 체크 표시는 일부 부서만 선택한 상태다. ‘전교회 대상도 함께’를 켜면 선택한 주관부서 외에도 전체 성도가 참여하는 공개 범위 내 행사를 함께 볼 수 있다. 주관부서 ‘전교회’의 원본 예산 책임 조직은 당회이며, 실제 참여 대상과는 별개다.

연간은 열두 달의 행사 밀도를, 월간은 날짜별 약속을, 목록은 큰 글씨로 시간·장소를 읽는 데 적합하다. 휴대폰은 목록으로 시작한다. 큰 글씨 버튼은 목록 중심으로 확대한다. 오늘 버튼은 한국의 오늘이 속한 연월로 돌아간다.

연간에서 월 이름이나 카드의 빈 곳을 누르면 해당 월간으로 이동한다. 연간·월간 모두 날짜에 볼 수 있는 일정이 한 개면 바로 상세를, 여러 개면 그날 목록을 연다. 일정이 없는 날은 편집 권한이 있을 때만 그 날짜의 입력창이 열린다. 교회력 참고 표시는 실제 행사 수에 포함되지 않는다. 행사 제목을 직접 누르면 언제나 그 행사 상세를 연다.

## 등록과 변경

실제 교회 계정으로 로그인하고 부서 담당 권한을 받아야 입력할 수 있다. 일정 이름·날짜·주관부서를 적고 종일 또는 시간을 고른다. 여러 날 일정은 마지막 날짜를 지정한다. 자정을 넘으면 다음 날을 마지막 날짜로 지정한다. 참여 대상과 공개 범위를 따로 선택한다.

전체 공개 일정의 안내·장소는 공개 게시판과 구글 캘린더에도 표시된다. 개인정보와 준비 담당자 메모는 ‘담당자 내부 메모’에 적는다. 교인공개는 승인된 로그인 성도에게, 주관부서 담당자공개는 해당 조직 권한이 있는 사용자에게만 보인다. 내부 메모는 편집 가능한 담당자만 보는 것이 원칙이다.

입력자와 수립일은 수정하는 필드가 아니다. 서버가 현재 로그인 사용자의 이름과 최초 등록 시각으로 기록한다. 상세에서 최초 기록과 마지막 변경자·변경일을 확인한다. 변경 이력을 펼치면 날짜·시간·장소 같은 변경 전후를 읽을 수 있다. 최초 수립 기록은 수정 뒤에도 남고 아무것도 바꾸지 않은 저장은 변경일을 갱신하지 않는다.

반복 일정을 수정할 때는 ‘이번 회차’와 ‘반복 전체’를 구별한다. 한 회차의 시간·장소는 예외로 남고 다른 회차는 유지된다. 주관부서·참여 대상·공개 범위·반복 규칙 변경은 반복 전체에서 한다. 취소는 이유를 남기고 최근 변경에서 확인한다. 삭제는 휴지통에 보관하며 권한이 있는 담당자가 복구할 수 있다. 반복 전체의 삭제와 한 회차 취소는 서로 다르다.

저장 중에는 버튼이 잠기고 실패한 입력은 남는다. 다른 사람이 먼저 변경했다는 안내가 나오면 최신 상세를 확인한 뒤 변경을 다시 적용한다. 서버 응답이 불확실하면 같은 내용을 유지해 재시도하고 임의로 새로운 등록을 반복하지 않는다.

## 공유와 개인 캘린더

공유하기에서 공개 게시판 주소를 복사한다. 현재 선택한 부서·연월·보기 방식을 담지만 내부 일정은 공개하지 않는다. 공개 게시판에서도 부서와 보기 방식을 바꿀 수 있다. 이번 주 안내 복사는 공개 일정만 포함하며 생성시각을 함께 적는다. 화면 인쇄는 현재 월간·연간·목록을 인쇄한다.

운영 서비스가 공개된 후 PC Google Calendar의 ‘다른 캘린더 + → URL로 추가’에 ICS 구독 주소를 넣는다. 처음 추가는 PC에서 한다. 휴대폰에서는 같은 Google 계정의 이 캘린더를 표시한다. 삼성 캘린더도 연결된 Google 계정의 표시·동기화를 확인하되 기기와 앱 버전에 따른 차이를 확인한다.

구독은 읽기 전용이고 개인 일정은 이 서비스로 가져오지 않는다. 구글의 갱신 지연은 서비스가 정하지 못하므로 급한 변경은 예봄일정의 최근 변경에서 확인한다. ICS 파일 다운로드 후 가져오기는 한 번의 복사이며 자동 갱신 구독이 아니다. 개발 미리보기 주소 대신 확정된 운영 주소로 구독한다.

## 교회력과 장소

절기는 한국 개신교의 서방 그레고리력 기준 참고다. 부활주일·성령강림·대림절·성탄절 같은 표시는 실제 등록 행사나 휴무를 의미하지 않는다. 추수감사주일 등 교회별 관행은 관리자가 정하며 기본값을 교회의 확정 계획으로 오인하지 않는다.

관리자가 등록한 장소를 고르면 같은 장소의 겹치는 일정을 안내한다. 이름을 직접 입력한 장소는 정규화된 예약 공간이 아니므로 자동 충돌 안내가 제한된다. 경고는 참고이며 장소 예약 승인 시스템을 대신하지 않는다. 내부 행사의 이름·시간을 경고로 외부에 노출하지 않는다.

## 관리자가 처음 준비할 일

보호된 환경설정에서 SSO 검증키·운영 주소·최초 실제 관리자 사용자 ID를 연결하고 교적부의 복귀 허용 목록을 확인한다. 가상 계정으로 대신하지 않는다. 실제 관리자가 로그인한 후 `/settings`에서 교회력·장소와 실제 로그인한 사용자의 부서 권한을 지정한다. 예산 금액 연계 검색은 Phase 2에서 추가하며 이 서비스의 등록이 재정부 예산을 자동 변경하지 않는다.
